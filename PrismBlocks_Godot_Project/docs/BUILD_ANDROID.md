# Android Build Instructions

## Prerequisites
1. Android Studio / Android SDK (API Level 33 or higher).
2. OpenJDK 17.
3. Godot 4.x Android Export Templates.

## Building APK
1. Open project in Godot Engine 4.
2. Go to **Project -> Export**.
3. Select **Android** export preset.
4. Click **Export Project** and save as `PrismBlocks.apk`.
