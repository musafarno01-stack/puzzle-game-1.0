# iOS Build Instructions

## Prerequisites
1. macOS running Xcode 14+.
2. Apple Developer Account & Provisioning Profiles.

## Steps
1. Export project from Godot Engine as an Xcode Project.
2. Open the `.xcodeproj` file in Xcode.
3. Configure Signing & Capabilities with your Apple Developer Team ID.
4. Build and archive for TestFlight or App Store distribution.
