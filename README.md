# Prism Blocks — Complete Godot 4 Mobile Game

Prism Blocks is an original, endless 8×8 block puzzle game designed for mobile devices (Android and iOS). Drag pieces onto the board, complete full horizontal rows and vertical columns to clear them, build high score combos, and save your progress locally.

## Features
- **8×8 Puzzle Grid**: Drag-and-place mechanics with smart tray generation.
- **Fair Play Guarantee**: Every tray generated guarantees at least one playable move if one exists on the board.
- **Save System**: Automatically persists high scores, theme choices, and settings.
- **AdMob Integration**: Support for Banners, Interstitials, and Rewarded Rescue Video Ads.
- **Original Assets**: Native 2D sprites, custom icons, and original synthesized sound effects.

## Quick Setup
1. Extract `PrismBlocks_Godot_Project.zip`.
2. Launch Godot Engine 4.x.
3. Click **Import**, navigate to the extracted directory, and open `project.godot`.
4. Press **F5** to run and play in the editor.
